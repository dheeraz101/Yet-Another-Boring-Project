How to List Your Project

  • Fork the Repository: Copy this ecosystem repository to your own GitHub account.
  • Update projects.json: Add your project details inside the "projects" array, including its name, date, description, live link, and GitHub link.
  • Verify constraints: Ensure your project description is under 150 characters and that you follow our clean design principles.
  • Include YABP Logo Badge: Display the YABP logo badge prominently in your project's repository README file.
  • Open Pull Request: Open a PR. The automated validation will double-check your code before approval!
